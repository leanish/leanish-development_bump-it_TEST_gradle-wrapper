# bump-it wrapper fixture

Public, disposable repository for a real bump-it Gradle wrapper update. It has
one Java class and one dependency-free test (`fixtureTest`, included in `check`).

```sh
./gradlew check --no-daemon
```

The starting wrapper is Gradle 9.7.1, built on 2026-08-19, stable and non-broken.
The wrapper files are generated by that real Gradle distribution and include its
official distribution SHA-256. On 2026-10-07, the tool's selection against all 18
published gradle/gradle advisories found no advisory affecting 9.7.1 and selected
9.8.0 for a routine update (9.8.1, built that day, is younger than seven days).

The Actions `Check` workflow runs on main and PRs. It checks out directly with git
so action-pin updates do not distract from this wrapper-only fixture. No third
party build dependencies or supply-chain gate workflow are needed for this test.
`.github/supply-chain.json` sets the seven-day window and the root Gradle build;
the operator opts in through the separate bump-it `agent.yaml`.

Nothing is published or merged by this fixture. The operator reviews the four
wrapper files and CI in the PR bump-it creates.

[EXPECTED.md](EXPECTED.md) distinguishes the historical selected target from
the live wrapper rule and documents supply-chain 0.3.0 acceptance.
